# 시연용 지원사업 데이터 정책

## 범위

- 실제 행정기관 지원사업과 FLOUT 시연을 위한 가상 사업을 구분합니다.
- PR #272에서 제안된 V66 시드는 시설 분류 3개(출입구·창호, 배수·역류, 침수 감지·경보)에 대해 `support_programs` 레코드를 추가합니다.
- **현재 dev 브랜치에 V66이 없으면 이 데이터는 dev에 반영되지 않은 상태입니다.**

## 구분 기준

- `external_code`: `DEMO-FACILITY-*`
- `name`: `[시연용]` 접두어
- `official_source`: `FLOUT 시연 데이터`
- `source_metadata`: `demo: true`
- `official_url`: 실제 공고 URL로 위장하지 않습니다.

## 운영 원칙

1. 일반 사용자에게 실제 시·도 공고인 것처럼 보이지 않도록 명시적으로 구분합니다.
2. 테스트 시 신청 데이터가 실제 지원사업에 결합되지 않도록 검증합니다.
3. 운영 배포에 포함할지 사전에 승인·검토합니다.
4. 데이터 제거 시 참조 중인 지원 신청 및 외래키 관계를 먼저 파악합니다.
5. 이미 적용된 Flyway 시드는 수정하지 않고 후속 마이그레이션 또는 비노출 정책으로 조정합니다.
