# 주민 홈 진행 현황 카드 문구

`GET /api/resident/progress`는 `title`을 반환합니다. 버튼 문구는 응답에 추가하지 않으며, 프론트에서 `currentStage`와 `nextAction.type`을 함께 사용해 표시합니다. 이동 대상은 기존 `nextAction.target`을 사용합니다.

| currentStage | nextAction.type | 버튼 문구 |
| --- | --- | --- |
| RISK_ASSESSMENT_IN_PROGRESS | WAIT_FOR_ASSESSMENT | 분석 현황 보기 |
| RISK_ASSESSMENT_FAILED | VIEW_ASSESSMENT | 분석 결과 확인 |
| RISK_ASSESSMENT_COMPLETED | VIEW_ASSESSMENT | 분석 결과 확인 |
| GUIDE_AVAILABLE | VIEW_GUIDE | 가이드 보기 |
| GUIDE_IN_PROGRESS | VIEW_GUIDE | 가이드 이어보기 |
| GUIDE_COMPLETED | CONSIDER_INSPECTION | 현장점검 알아보기 |
| INSPECTION_FORM_EDITING | CONTINUE_INSPECTION_FORM | 이어서 작성 |
| INSPECTION_DRAFT | UPLOAD_INSPECTION_PHOTO | 사진 등록 |
| INSPECTION_RECEIVED | WAIT_FOR_VISIT_SCHEDULE | 신청 현황 보기 |
| VISIT_SCHEDULED | VIEW_VISIT_SCHEDULE | 일정 확인 |
| INSPECTION_IN_PROGRESS | VIEW_INSPECTION_PROGRESS | 진행 현황 보기 |
| INSPECTION_RESULT_PENDING | WAIT_FOR_RESULT | 점검 현황 보기 |
| INSPECTION_RESULT_PUBLISHED | CHECK_SUPPORT_OPTIONS | 지원사업 알아보기 |
| SUPPORT_FORM_EDITING | CONTINUE_SUPPORT_FORM | 이어서 작성 |
| SUPPORT_DRAFT | UPLOAD_LANDLORD_CONSENT | 동의서 등록 |
| SUPPORT_REVIEW | VIEW_SUPPORT_PROGRESS | 검토 현황 보기 |
| SUPPORT_APPROVED | VIEW_CONSTRUCTION_SCHEDULE | 시공 일정 확인 |
| SUPPORT_REJECTED | VIEW_REJECTION | 반려 사유 확인 |
| CONSTRUCTION_SCHEDULED | VIEW_CONSTRUCTION_SCHEDULE | 일정 확인 |
| CONSTRUCTION_IN_PROGRESS | VIEW_PROGRESS | 진행 현황 보기 |
| CONSTRUCTION_COMPLETED | VIEW_COMPLETION | 완료 내용 확인 |

`VIEW_GUIDE`와 `VIEW_CONSTRUCTION_SCHEDULE`은 같은 행동 유형이라도 단계에 따라 버튼 문구가 다릅니다. 각각 `GUIDE_AVAILABLE`/`GUIDE_IN_PROGRESS`, `SUPPORT_APPROVED`/`CONSTRUCTION_SCHEDULED`를 구분해야 합니다.
