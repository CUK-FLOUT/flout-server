# AI 지역 상대 취약도 모델 파이프라인

> 백엔드의 추론 API 연동은 구현되어 있습니다. 모델 파일과 등급 경계값은 Python
> 배포 환경에서 관리하며, Spring-Python 런타임 계약은
> [AI 지역 상대 취약도 분석 API](risk-assessment-ai.md)를 참고하세요.

## 문제 정의

모델은 100m 격자마다 과거 침수 기록 유무인 `flooded`를 정답으로 학습하는 이진 분류
모델입니다. 추론 시 반환하는 0~1 점수는 해당 격자의 지형·토지피복 조건이 과거 침수
지역과 얼마나 유사한지를 나타냅니다. 개별 주택의 침수 확률이나 안전 여부를 직접
예측하지 않습니다.

`HIGH`, `CAUTION`, `LOW`는 모델이 직접 학습하는 정답 클래스가 아닙니다. 공간 교차
검증에서 얻은 점수 분포를 기준으로 고정한 경계값을 적용하는 화면 표시 규칙입니다.

| 표시 등급 | 상대 순위 | 점수 경계 |
| --- | --- | ---: |
| `HIGH` | 검증 점수 상위 10% | `score >= 0.1905` |
| `CAUTION` | 상위 10~40% | `0.0475 <= score < 0.1905` |
| `LOW` | 나머지 60% | `score < 0.0475` |

조회 좌표에 해당하는 격자가 없으면 `LOW`로 대체하지 않고 분석 불가로 처리합니다.

## 데이터와 입력 변수

| 데이터 | 출처 | 모델 활용 |
| --- | --- | --- |
| 침수흔적도 | 행정안전부 재난안전데이터 공유플랫폼 오픈 API, 2002~2022 | 격자별 침수 기록 정답 |
| 지표면 높이 | Copernicus DEM GLO-30 | 높이·경사·주변 대비 높이·움푹한 지형 여부 |
| 토지피복 | ESA WorldCover 2021 v200 | 건물·도로·녹지·농지·맨땅·물 비율과 물까지 거리 |
| 도시침수지도 | 한강홍수통제소 부천 100년 빈도 | 모델 입력에서 제외하고 결과 비교에만 사용 |

위도 37~38도, 경도 126~128도 범위를 위도 3초 × 경도 4초 크기의 약 100m 격자로
분할합니다. 초기 약 216만 격자에서 고정 규칙으로 물 비율 50% 이상, 건물·도로 비율
10% 미만인 산·논밭 격자를 제외했습니다.

최종 입력 변수는 다음 12개입니다.

| 구분 | 입력 변수 |
| --- | --- |
| 지형 | `elev`, `slope`, `rel_elev_500`, `rel_elev_1k`, `sink` |
| 토지피복 | `built`, `built_500`, `green`, `crop`, `bare`, `water`, `dist_water` |

위도·경도는 위치 암기를 막기 위해 입력에서 제외합니다. 침수 연도·깊이·겹친 기록 수도
정답에서 파생된 값이므로 입력하지 않고 참고 열로만 보관합니다.

## 학습·검증 데이터 분리

| 구분 | 격자 수 | 침수 기록 격자 | 침수 비율 |
| --- | ---: | ---: | ---: |
| 학습: 서울·경기 | 438,087 | 7,170 | 1.6% |
| 홀드아웃: 부천 일대 | 7,832 | 151 | 1.9% |
| 제외: 홀드아웃 주변 1km | 3,617 | 32 | 미사용 |

- 부천 일대는 위도 37.455~37.555, 경도 126.735~126.835의 사각형으로 고정했습니다.
- 부천 홀드아웃과 주변 1km 격자는 최종 평가 전까지 학습·모델 선택·경계값 산정에
  사용하지 않았습니다.
- 인접 격자를 무작위로 나누면 공간 자기상관으로 성능이 부풀려질 수 있으므로, 학습
  지역을 20km 공간 블록으로 묶은 `GroupKFold(5)`를 사용했습니다.

## 모델 개발 파이프라인

```mermaid
flowchart LR
    A["침수흔적도<br/>지형 · 토지피복"] --> B["100m 격자와<br/>12개 변수 생성"]
    B --> C["서울·경기 학습<br/>부천·주변 1km 분리"]
    C --> D["20km 공간 블록<br/>5-fold 교차 검증"]
    D --> E["Random Forest<br/>최종 모델 고정"]
    E --> F["전체 학습 데이터로<br/>1회 재학습"]
    F --> G["부천 홀드아웃<br/>최종 평가 1회"]
    G --> H["고정 경계값으로<br/>표시 등급 산출"]
```

1. 침수흔적도, DEM, 토지피복 데이터를 같은 100m 격자에 결합합니다.
2. 값 범위·분포·중복·결측을 점검하고 학습과 무관한 고정 규칙 필터만 적용합니다.
3. 부천 홀드아웃과 주변 1km 완충 지대를 학습 데이터에서 먼저 분리합니다.
4. 서울·경기 학습 데이터에서 20km 공간 블록 5-fold 교차 검증 점수를 생성합니다.
5. 교차 검증 결과로 모델과 점수 경계값을 고정합니다.
6. 전체 학습 데이터로 최종 모델을 재학습합니다.
7. 이전 단계에서 사용하지 않은 부천 홀드아웃에 한 번 적용해 일반화 성능을 평가합니다.
   홀드아웃 결과로 모델·입력 변수·경계값을 다시 선택하지 않습니다.

## 최종 모델

1차 비교에서는 로지스틱 회귀, Random Forest, LightGBM, XGBoost를 동일한 20km 공간
블록 조건에서 평가했습니다. 트리 계열 모델이 로지스틱 회귀보다 우수했고, 공간 검증
PR-AUC가 가장 높으며 구조가 단순한 `RandomForestClassifier` 1개를 최종 모델로
확정했습니다.

| 하이퍼파라미터 | 값 | 의미 |
| --- | --- | --- |
| `n_estimators` | `300` | 결정 트리 300개 |
| `min_samples_leaf` | `10` | 잎당 최소 10개 격자 |
| `max_features` | `sqrt` | 분기마다 입력 변수 일부 사용 |
| `max_samples` | `0.3` | 트리마다 학습 데이터 30% 사용 |
| `class_weight` | `balanced_subsample` | 희소한 침수 격자 가중치 보정 |
| `random_state` | `0` | 재현 가능한 학습 |

## 평가 지표와 선정 기준

침수 격자는 학습 데이터의 약 1.6%이므로, 모든 격자를 침수 없음으로 예측해도 높게
나오는 정확도는 사용하지 않습니다.

| 지표 | 용도 |
| --- | --- |
| PR-AUC | 희소한 침수 격자를 비침수 격자보다 위에 배치하는지 확인하는 주요 지표 |
| 상위 10% 포착률 | 모델 점수 상위 10%에 실제 침수 격자가 얼마나 포함되는지 확인 |
| ROC-AUC | 전체 순위 구분력을 확인하는 보조 지표 |
| 10분위별 침수율 | 점수가 높아질수록 실제 침수율도 높아지는지 확인 |
| 등급별 실제 침수율 | 화면 표시 구간이 실질적인 차이를 갖는지 확인 |

모델은 부천 홀드아웃을 열기 전에 20km 공간 교차 검증의 PR-AUC를 우선하여 고정했고,
상위 10% 포착률과 ROC-AUC를 함께 확인했습니다. 등급 경계 역시 교차 검증 점수의 상위
10%, 40% 분위수로 미리 고정했습니다. 부천 홀드아웃은 최종 모델과 경계값의 일반화
성능을 확인하는 데만 사용했습니다.

## 최종 평가 결과

| 평가 구간 | PR-AUC | ROC-AUC | 주요 결과 |
| --- | ---: | ---: | --- |
| 서울·경기 공간 검증 | 0.069 (무작위 0.016) | 0.813 | HIGH와 LOW의 실제 침수율 18.3배 차이 |
| 부천 홀드아웃 | 0.088 (무작위 0.019) | 0.775 | 상위 10%가 침수 격자의 36.4% 포착, HIGH와 LOW 14.6배 차이 |

부천 홀드아웃에서 실제 침수 격자의 95.4%가 `CAUTION` 이상에 포함됐습니다. 이는
점수와 표시 구간이 지역 우선순위를 정하는 데 의미가 있음을 보여주지만, 개별 주소의
침수 여부를 확정한다는 뜻은 아닙니다.

## 서비스 연동

Spring 서버는 주소를 좌표로 변환한 뒤 Python 서비스의
`GET /api/vulnerability?lat={latitude}&lon={longitude}`를 호출합니다. 응답의 위험 유형,
상태, 격자 ID, 0~1 점수, 등급, 침수 기록 안내와 주의 문구를 검증한 뒤 저장합니다.

화면에서는 “침수 위험” 대신 “지역 상대 취약도”를 사용합니다. `HIGH`는 “침수 확정”이
아니라 “주의가 필요한 동네”로 설명하고, 침수 기록 없음도 안전을 의미하지 않는다고
안내합니다.

## 한계

- 침수 기록 0은 실제로 안전하다는 뜻이 아니라 기록이나 신고가 없다는 뜻입니다.
- 침수흔적도는 시기와 지역에 편향이 있으며 부천의 2022년 폭우 기록이 누락됐습니다.
- 부천 홀드아웃의 침수 표본은 151개로 작아 모델 간 우열을 확정하기 어렵습니다.
- DEM 해상도는 30m, 서비스 격자는 100m이므로 골목 단위 지형 차이를 반영하지 못합니다.
- 도시침수지도와 일치도가 낮아 보완 자료로만 사용합니다.
- 홀드아웃은 행정 경계가 아닌 사각형이므로 서울·인천 일부가 포함됩니다.

따라서 모델 결과는 현장점검과 예방 행동의 우선순위를 돕는 참고 정보로만 사용합니다.
