# 운영자 내부 메모 저장

## PATCH /api/admin/applications/{applicationId}/internal-memo

Swagger 그룹: `운영자-GIS 신청관리`

운영자 Access Token을 `Authorization: Bearer {accessToken}` 헤더로 전달합니다.
`applicationId`는 양의 정수이며 본문은 `application/json`입니다.

```json
{
  "internalMemo": "방문 전 연락하여 출입 가능 여부를 확인해주세요."
}
```

- `internalMemo`는 필수 문자열이며 최대 2000자입니다. 누락·null은 400입니다.
- 앞뒤 공백을 제거하여 저장하며, 빈 문자열 또는 공백만 보내면 DB에 NULL을 저장해 삭제합니다.
- 기존 메모 전체를 교체합니다. 여러 운영자가 저장하면 마지막으로 성공한 저장 내용이 남습니다.
- 메모 컬럼만 갱신하며 신청 상태, 접수번호, 신청 내용, 처리 이력은 변경하지 않습니다.
- 내부 메모는 운영자만 저장할 수 있으며 주민 신청 응답에는 포함하지 않습니다.
- 기존 `inspection_applications.internal_memo` 컬럼을 사용하므로 새로운 DB 마이그레이션은 없습니다.

### 관할 지역

현재 등록된 관할인 부천시를 지원합니다. 운영자 관할 지역이 `부천시`이고 신청 주소가
`부천시`, `경기 부천시`, `경기도 부천시`로 시작하는 경우만 수정할 수 있습니다.
행정구역 이름 뒤의 공백 또는 문자열 끝을 확인하여 `부천시민로` 등 부분 일치는 허용하지 않습니다.
신청 주소는 주민 신청 시 저장한 분석 결과 주소를 사용하고, 요청으로 운영자 ID나 관할을 지정할 수 없습니다.
관할 미지정·다른 지역·불명확한 주소는 403을 반환합니다. 다른 지역 지원 시 관할 판정 정책도 확장해야 합니다.

### 성공 응답

```json
{
  "isSuccess": true,
  "status": 200,
  "code": "APPLICATION_200_1",
  "message": "내부 메모가 저장되었습니다.",
  "result": {
    "applicationId": 1,
    "internalMemo": "방문 전 연락하여 출입 가능 여부를 확인해주세요."
  },
  "timeStamp": "2026-10-28 19:00:00"
}
```

삭제 시에도 동일한 성공 코드로 `result.internalMemo: null`을 반환합니다.

### 오류

| 상태 | 코드 | 의미 |
| --- | --- | --- |
| 400 | COMMON_400_2 | 메모 누락·null·2000자 초과 또는 잘못된 JSON |
| 400 | COMMON_400_3 | 신청 ID 형식·범위 오류 |
| 401 | COMMON_401_1 | 인증 토큰 누락 |
| 401 | COMMON_401_3 | 유효하지 않거나 만료된 토큰 |
| 403 | COMMON_403_1 | 운영자 권한 없음 |
| 403 | APPLICATION_403_3 | 관할 외 신청 또는 관할 미지정 |
| 404 | APPLICATION_404_2 | 신청 없음 |
| 406 | COMMON_406_1 | 지원하지 않는 응답 형식 |
| 415 | COMMON_415_1 | 지원하지 않는 요청 본문 형식 |
| 500 | COMMON_500_1 | 서버 내부 오류 |
